07/11/2026 (re-sent 11/11/2026), as text. Names of candidates and staff are replaced by a placeholder
in square brackets or by the role; blank form lines are written as `[ ]`. The originals stay with
MyCity; this repository is public, so only these copies live here (AJ, 11/11/2026).
